# GPS 暗室结题文件整理协同仓库

本仓库只用于同步 GPS 暗室结题整理状态和下达文件整理任务。GPT 负责阅读状态、按结题清单提出具体文件任务；本机 Codex 负责在项目目录核实来源、复制文件、校验副本并回报结果。

## 协作规则

1. GPT 下达任务时必须写明清单编号、整理目的、精确源路径、整理目录中的目标路径、复制范围和校验方式。优先复用已有副本，不重复复制。
2. 普通文件整理按任务单执行：只复制、不移动原件；完成后比较文件数、大小和 SHA-256，并把结果记入对应 GitHub Issue。
3. 文件缺失、来源版本冲突、清单要求与现有证据不符，或任务要求读取/上传原始 IQ、运行 GNSS-SDR/MATLAB/SAGE、改动工程或论文状态时，先停下并报告用户。
4. 结题材料只关注 GPS 和暗室；暗室设施材料以用户提供的两件文件为限。用户确认两件资料对应同一暗室且已通过验收，报告中应把验收结论归于项目方确认。
5. 本仓库里的状态是结题整理快照。工程/科学状态仍以项目中的 `docs/GNSS_SAGE_ENGINEERING_HANDOFF_CURRENT.md` 和对应 QA、manifest 为准。

## GPT Commander 使用方式

将本仓库连接到 ChatGPT 的 GitHub 插件。让 GPT 先阅读 `GPS_当前状态.md`、`GPS_清单逐项对照.md`、`GPS_逐项整理动作表.md` 和 `任务单模板.md`，再按 A/B/C 清单编号提出一个具体整理任务。若该 GPT 的 GitHub 连接器允许创建 Issue，可将任务写成 Issue；否则把任务单带到本机 Codex。GPT 不会自动唤醒本机 Codex；开始执行时由用户指定 Issue 编号或粘贴任务单。完成后记录校验结果。
